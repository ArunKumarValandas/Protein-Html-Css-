# 🐦 Twitter Clone

A simple **Twitter Clone** built using **HTML, CSS, and JavaScript**. Users can write tweets, post them instantly, and like/unlike tweets with a single click.

## 🚀 Features

* ✍️ Write a tweet
* 📏 Character limit (281 characters)
* 📨 Post tweets instantly
* ❤️ Like and Unlike tweets
* 🆕 New tweets appear at the top
* 🎨 Clean and responsive user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (DOM Manipulation)

## 📂 Project Structure

```
Twitter-Clone/
│── index.html
│── twitter.css
│── twitter.js
│── README.md
```

## ▶️ How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Make sure the following files are in the same folder:

   * `index.html`
   * `twitter.css`
   * `twitter.js`
4. Open `index.html` in any web browser.

## 📖 How It Works

1. Type your message in the text area.
2. Click the **Tweet** button.
3. The tweet is added to the top of the feed.
4. Click **💖 Like** to like a tweet.
5. Click it again to toggle back to **💖 Like**.
